# Architect

*Lesson 04 · Overview — Lyzr Overview & Offerings*

## What you'll learn

- Understand the role of Lyzr Architect as a whiteboard planning and design engine.
- Discover how Architect automatically generates project specs, UI layouts, and agent flows.
- Learn how to transition from an approved visual plan to active agents in Lyzr Studio.

## Key concepts

**Lyzr Architect is the most sophisticated layer for visual planning.** Users can whiteboard their application concept, sketching out how they want the system to behave.

**Architect automatically drafts detailed system documents and UI blueprints.** It specifies the interface layout, the backend agents, and the flow of communication between different subagents.

**An approved Architect plan compiles directly into active agents in Studio.** Once you proceed with the generated blueprint, the platform provisions the corresponding agents and outputs a functional front-end out-of-the-box.

## In Studio

- Open the Architect workspace to view the visual layout designer and document generator.
- Walk through the flow of accepting an Architect plan and verifying the newly generated agents in Studio.
