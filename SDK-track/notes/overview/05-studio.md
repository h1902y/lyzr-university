# Studio

*Lesson 05 · Overview — Lyzr Overview & Offerings*

## What you'll learn

- Explore the SaaS UI dashboard of Lyzr Studio.
- Learn how to build and configure agents in a low-code visual interface.
- Understand the equivalence between UI actions, API endpoints, and SDK code.

## Key concepts

**Lyzr Studio is a low-code SaaS interface for creating and managing agents.** It serves as the primary workspace for business users and developers to orchestrate agent behaviors visually.

**Every action performed in the Studio UI is fully mapped to APIs and SDKs.** You can build agents by clicking buttons in the dashboard, invoking REST endpoints, or writing Python code using the Lyzr SDK.

**Studio streamlines the creation of knowledge bases and tool integrations.** Instead of writing database connectors, users can manage grounding knowledge and custom tools via simple visual panels.

## In Studio

- Explore the Studio home screen, showing the agents list, knowledge bases, and tool panels.
- Walk through the visual creation of a new agent, setting its role, goal, and system instructions.
