# Computer Agent

*Lesson 07 · Overview — Lyzr Overview & Offerings*

## What you'll learn

- Understand the concept and capabilities of Lyzr Computer Agent.
- Learn how to bring your own agent code, harness, and runtime environments.
- Discover how Computer Agent routes output to external communication channels.

## Key concepts

**Computer Agent allows you to run custom agent code from Git repositories.** You can host your agent files on GitHub or GitLab and import them directly into the Lyzr harness.

**Users retain complete control over the harness, runtime, and memory.** Instead of relying on hosted cloud sandboxes, you specify exactly where the agent runs and how its conversations are persisted.

**Output can be routed seamlessly to any enterprise communication channel.** The agent can write directly to Slack, Teams, email, or custom webhooks once execution finishes in your runtime.
