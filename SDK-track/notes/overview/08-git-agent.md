# Git Agent

*Lesson 08 · Overview — Lyzr Overview & Offerings*

## What you'll learn

- Discover the concept and utility of Lyzr Git Agent.
- Learn how to define roles, goals, tools, models, and skills entirely in a Git repo.
- Understand how to install and execute a Git Agent with a single command.

## Key concepts

**Git Agent is a Git-native multimodal AI agent harness.** In this model, the complete definition of the agent—its instructions, model, tools, and skills—lives as configuration files in a Git repository.

**Storing agent definitions in Git enables robust version control and collaboration.** You can use standard pull requests, code reviews, and commit histories to track and manage changes to your agentic workflows.

**Git Agent can be installed and executed with a single shell command.** This lightweight, CLI-driven approach makes it simple to integrate agent execution into CI/CD pipelines and local terminal environments.
