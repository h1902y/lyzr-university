# Welcome to Agent Studio & the lifecycle

*Lesson 01 · Foundations · The Agent Lifecycle*

## What you'll learn

- Name the five lifecycle stages — Build, Govern, Test, Deploy, Monitor — and point to where each one lives in the Studio left-nav.
- Tell the four agent types apart on the home screen and pick the right one for a job: Agent, Managerial, Superflow, Voice.
- Choose between the two ways to start a build: describe it in plain English and let Lyzr's architect draft it, or build it by hand from an agent type.
- Find any agent you've made in the Agent Registry and open, edit, or share it from there.
- Frame the rest of this series — one customer-support agent carried from a blank page to live and monitored.

## Key concepts

**The hard part of agents isn't the talking — it's everything around it.** Getting a model to respond is the easy 10%. Governing it, testing it, deploying it, and watching it once it's live is the work that decides whether an agent survives production. Studio is built around that whole arc rather than just the chat box.

**One loop runs the entire product: Build → Govern → Test → Deploy → Monitor.** These five stages are the same for every agent you'll ever make in Studio, and the left-hand nav is organized to match them. You build the agent and give it knowledge, you govern it with guardrails under connections, safety, and evaluations, you test it, you deploy it, then you keep an eye on it under monitoring. Learn the loop once and the nav stops being a menu and becomes a map.

**Studio gives you two on-ramps to a new agent — describe or build.** At the top of the home screen you can describe what you want in plain English and let Lyzr's architect draft the agent for you, or you can assemble it yourself from one of the agent types. This series builds by hand so you see every piece, but the plain-English route is there when you want speed.

**The agent type you pick sets the shape of the agent.** Studio offers four: a single-focus **Agent** for one job, a **Managerial** agent to coordinate several agents, a **Superflow** for multi-step workflows, and **Voice** for phone and IVR. Our customer-support agent is a single-focus Agent.

**The Agent Registry is your home base.** Every agent you create lives in the Registry, ready to open, edit, or share. By the end of this series, the support agent we build together will be sitting there — live.
