# 📖 Thinkific Manual Upload Guide with Plain Markdown Notes

This guide provides step-by-step instructions and plain Markdown content for manually uploading lessons to **Thinkific** (`lyzr.thinkific.com`).

---

## 📁 1. Master Course Structure & Names

| Track # | Official Production Title | Thinkific Course ID | Target Audience |
| :---: | :--- | :---: | :--- |
| **Track 1** | **Lyzr Foundations** | `#3489968` | Anyone new to Lyzr & Agentic AI |
| **Track 2** | **Lyzr Platform Studio** | `#3489969` | Product Leaders & Operations (No-Code Workflows) |
| **Track 3** | **Lyzr Code Libraries** | `#3489970` | Python Engineers & AI Developers (ADK SDK) |

---

## 🛠️ 2. Step-by-Step Thinkific Upload Instructions

1. Log in to **Thinkific Admin** $\rightarrow$ [lyzr.thinkific.com/manage/courses](https://lyzr.thinkific.com/manage/courses).
2. Rename the 3 master courses:
   * Course `#3489968` $\rightarrow$ **Lyzr Foundations**
   * Course `#3489969` $\rightarrow$ **Lyzr Platform Studio**
   * Course `#3489970` $\rightarrow$ **Lyzr Code Libraries**
3. Select the target course & expand the target chapter.
4. Click **Add Lesson** $\rightarrow$ Select **Video** $\rightarrow$ Upload the MP4 from `university/revamp_branded/`.
5. Add/edit the lesson **Text Block** $\rightarrow$ Paste plain Markdown text.
6. Click **Save** & set toggle to **Published**.
