## What's different about Lyzr

- **Provider-agnostic by design.** One string change moves the agent between OpenAI, Anthropic, Google, and the rest. Build once.
- **RAG, memory, tools as primitives.** Not bolt-ons. Not three libraries glued together. One coherent surface.
- **Production-shaped.** Streaming, structured outputs, file handling, error states — present from lesson one, not appendix material.
- **One Python module.** `from lyzr import Agent` and you're already building.

**Do I need to know AI?**
No. Lesson 01 starts at *what is an agent*. If you know Python, you're ready.

**Do I need a Lyzr account?**
Yes — free tier. You'll set it up in lesson 02. No credit card required.

**Will this be paid later?**
Not in our plan. This course is the on-ramp.

**Can I get the code?**
Yes. Every lesson links to its code, and the four capstone projects ship as full repositories.

**How long does it take?**
Self-paced. Some developers finish in a weekend; most spread it across two to three weeks. The course doesn't expire.

**Is there a certificate?**
Yes — issued through Thinkific when you complete all 19 lessons.
