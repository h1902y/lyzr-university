# Theme v4 Requirements & Framer Academy Inspiration Spec

**Status:** Future Roadmap (Deferred from v3)  
**Reference:** Framer Academy Fundamentals (`https://www.framer.com/academy/courses/fundamentals`)

---

## 🎯 Overview

Theme v4 will introduce advanced learning features and an ultra-polished 2-column course detail layout inspired by Framer Academy.

---

## 🚀 Key Feature Requirements for Theme v4

### 1. 2-Column Course Detail Layout
* **Left Column:** Deep curriculum breakdown with numbered chapters and lesson rows.
* **Right Column (Sticky Card):** Floating summary card displaying:
  * Course thumbnail art & video preview
  * Total duration (e.g. `⏱️ 4h 6m`)
  * Skill level badge (`📶 Beginner` / `Intermediate` / `Advanced`)
  * Primary enrollment button (`[ Start Learning Free ]`)

### 2. Per-Lesson Timestamps & Media Badges
* Display individual video runtimes right-aligned on every lesson row (e.g. `Getting familiar with interface — 5:16`).
* Distinguish media types with clean icon pills:
  * `▶️ Video Lesson` (`5:16`)
  * `📄 PDF Study Notes` (`2 Pages`)
  * `🛠️ Capstone Project Code`

### 3. Lyzr AI Concept Dictionary / Glossary
* Interactive reference tab/drawer for AI agent terminology:
  * **RAG (Retrieval-Augmented Generation)**
  * **MCP (Model Context Protocol)**
  * **Agent Memory & Vector Stores**
  * **Tool Calling & Multi-Agent Orchestration**
* Searchable and accessible directly from the lesson viewer.

### 4. Persistent Left Sidebar Navigation
* Left sidebar for easy navigation across learning resources:
  * 🏠 **Academy Home**
  * 🎓 **Courses**
  * ▶️ **Video Library**
  * 📖 **AI Dictionary**
  * 💬 **Community & Help**

### 5. Interactive Numbered Chapter Accordions
* Standardized chapter headings (`1. Welcome to Lyzr`, `2. Building & Orchestrating`, `3. Grounding in Knowledge`).
* Expandable/collapsible accordion animation with lesson completion progress indicators.
