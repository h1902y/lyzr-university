### Where to pull each (Thinkific admin)

1. **New sign-ups** — Support Your Students → Reports → **Users**; filter by sign-up date for the week.
2. **New enrollments** — Analytics → **Enrollments dashboard**; set time period to the week (enrollments *started*).
3. **Completions** — Same Enrollments dashboard (enrollments *completed*); per-course detail in **Progress Reports**.
4. **Completion rate** — Enrollments dashboard pie (% started vs % completed).
5. **Engagement** — Analytics → **Engagement dashboards** → Course Engagement (`Total Time Spent`, `Average Time to Complete`) + **Video Engagement Reporting** (hours watched, avg engagement %). ⚠️ Requires Advanced Analytics (Grow/Plus tier) — if unavailable, leave blank and we track video hours only / drop this metric.
6. **Certificates** — No standalone report; equals completions of cert-enabled courses. Use #3 filtered to courses that issue certs.

### Conventions
- Weeks are **Monday-anchored** (Mon → Sun); filename = the Monday date.
- Numbers are **cohort-seeded** in the early weeks (Agentpreneur C2 members granted access), not organic sign-ups — note that in the Read until organic traffic starts.
- WoW = change vs. previous week's file. Cumulative = running total since launch.
