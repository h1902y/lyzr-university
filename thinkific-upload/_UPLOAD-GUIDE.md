## 3 · How to upload one course

1. **Products → Courses → New course** — name it the course title above (or open the existing one).
2. Tag it with the Categories listed in its row.
3. Open the folder, select all files (`⌘A`), drag into the **Content Uploader**. One file → one lesson; don't leave the tab mid-upload.
4. Reorder / rename lessons as needed (8-dot handle).
5. **Coming-soon courses** publish with a *Coming soon* marker. When real lessons are recorded, delete the `0N *.pdf` placeholders first, then upload the real videos + notes.

> **Two number systems:** the folder prefix `NN` is the course index (01–40). Inside `1 - Tracks/ADK/04 ADK Tools and Workflows/` the files keep their SDK-track lesson numbers (`16a`/`16b`) — that's correct, don't renumber them.
